# Punchy Guy

Throw punches and knock the robots out. The score is how many you can KO.

**Play it:** https://vivchinu.github.io/punchy-guy/

Tap for a jab, flick sideways for a hook, and swipe up for an uppercut. You have three hearts.

**Place on the floor** uses ARCore. Open the site in Chrome on an Android phone, look at the floor until the ring sticks, then tap to start the fight. Real objects in front of the camera block the glove and the robots when the phone allows depth.

**Practice ring** works in a desktop browser with no camera.

To run it on this computer:

```
npm install
npm start
```

Then open http://localhost:8080. The phone AR links are printed when the server starts.
